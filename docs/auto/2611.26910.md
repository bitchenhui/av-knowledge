## 1. 背景与动机

论文把“自我改进”严格限定为**固定权重下跨回合的经验利用**（作者自认同 AgentOdyssey 的 test-time continual learning 语境），明确排除“在自输出上训练模型”那一支；也不含控制器的在线改进（本版控制器固定，留作未来工作）。核心动机是测量学层面的批评：既有基准分别测任务进度（游戏/具身基准）、世界知识 QA 与情景记忆（AgentOdyssey）、符号世界中的实验式知识获取（ExplorationBench），但任何单轴都会误读改进——**答对不等于观察到证据**（文中引 Garg et al. 2026：从未到达目标的具身 QA 智能体仍能答对 45.5% 的题，约等于无图像水平）；**记忆增长不等于新发现**；**进度依赖未必按意图执行的动作**。归因研究（Rashkin et al. 的 attribution、NExT-GQA 的视频时序定位）早已表明答案与支撑证据必须分开检查，而对自主探索的 agent，证据还必须能在**它自己采集的经验**中找到。

载体选 Outer Wilds：每回合约 22 分钟游戏时间后太阳超新星、世界完全重置，唯有玩家知识跨循环存留（类 meta-RL 的 trial 结构，Duan et al. 2016）。关键在于循环内部：游戏**无显式任务奖励**，进度信号稀疏且隐式（ship-log rumor 揭示、到达命名地点），且大多被知识门控。论文列举的困难场景构成一张“知识类型×世界性质”矩阵：Ash Twin Project 只能在沙 draining 后、Ember Twin 正上方时从唯一塔进入（最早约醒后 8 分钟，时间窗）；Ember Twin 最低城区会被上涨流沙封死（循环内不可逆）；Giant's Deep 电层之下核心只有借绝缘水母穿越（功能知识开门）；反向旋转的龙卷风外观与同类相似却把船拽入洋流之下（同貌异果）；Brittle Hollow 地壳自行崩解落入黑洞（世界按自身日程变化，一次到访不够）；ghost matter 肉眼不可见、仅 scout 照片可见且致命（仅仪器可见）；沙柱可劫持玩家/飞船偏离航线（环境可覆盖控制）。这些性质的直接后果是：**执行失败会伪装成知识失败**（它改变了 agent 能采到什么证据），本版不分离二者——这是解读全部实验数字时必须携带的口径。

由此提出三视图主张：知道什么、自身证据是否支持所知、走到多远，是同一次改进的三个投影，可能彼此脱节。概念上借 Tulving 的划分：答案是语义知识，引用是情景记忆。

## 2. 方法总览

基准由三层构成：游戏侧 mod 的全帧仪器化录制、三通道测量、双家族 LLM 评委。**成本模型**：主成本为循环数，副成本为游戏时间——游戏时钟只在 agent 执行时走、规划时冻结，规划开销不计入游戏时间。

**进度通道**：place = 游戏命名区域在本 run 中首次进入（扣除出生区域）；rumor fact = ship-log rumor 首次揭示（扣除初始存档已揭示项）。报告每循环后的累计数与八循环累计数之和，后者即发现曲线下面积：奖励早发现优于最后扎堆发现，且不需要最优参考策略——对无显式奖励的世界这是规避“最优轨迹参照”的务实设计。

**知识通道**：164 道单事实题，从游戏 wiki 撰写、未参考任何 agent 记录，仅用游戏呈现给玩家的名称；按八类知识标注（appearance 18 / spatial 20 / identity 36 / function 19 / causal 14 / temporal 6 / narrative 41 / procedural 10），类型学构建于 OpenEQA、NExT-QA 的类别、Ilievski 常识维度与 Anderson 程序性知识；narrative 为新增类（家庭场景无故事）。作者明示标签未经第二标注人校验。证据类型（观察——肉眼/仪器、证言——对话/文字、交互——自身动作的结果，取自发展心理学 Gopnik/Harris & Koenig 的三分）**属答案而非问题**。

**作答协议**：评 loop L 时，被测 LLM 用 loop L 末的记忆作答，可检索 loops 1..L 的记录与帧（绝不更晚）；每题引用至多 3 条证据，各含 loop、帧区间、天体与 xyz、简短来源，或答“证据不足”；单条证据未必覆盖答案全部要件（如外观题可能既需实体指认又需外观观察）。

**评分管线**分三步：程序校验（帧存在于 ≤L 的循环、引用天体与录制一致、首帧位置偏差 30 单位以内）→ 正确性评委（对参考答案判 correct/wrong/no answer，允许 agent 用自命名只要唯一指认）→ grounding 评委（只看被引帧、录制的天体/位置/游戏时间与程序校验结果，**不看参考答案**，判定证据是否既展示答案又绑定到问题所指实体；可请求更多帧，但引用区间外的帧不能补缺事实，唯一例外是对话开头的 "Talk to" 提示）。计分：correct+grounded 记 +1，correct 但未 grounded 记 **−1**，错/未答记 0，164 题求和缩放到 [−100, 100]。设计意图直白：无法自证的答对要倒扣，因为“它如何学到该事实”的陈述站不住。评委为一名 GPT-6.1 Sol 与一名 Gemini 4 Argon（与 planner 同模型），逐题双评，报告 Cohen's κ（未答题计为同一决策）。

## 3. 关键设计

**（1）仪器化录制：可校验证据的地基。** mod 每帧记录手柄输入、步行/飞船状态、所在或最近天体、相对该天体的 xyz、速度、朝向、角速度与游戏时间；支持冻结/恢复；命名区域进入与 rumor 揭示事件只送 scorer、对 agent 不可见。这实质是视频帧+控制流+位姿遥测的**多流同步采集**问题，步长 0.056 s、规划期冻结，保证“证据 = 帧区间 + 几何位置”可被程序硬校验——grounding 协议的全部可信度建立在这个同步录制的确定性上。

**（2）面向上下文预算的关键帧抽取。** planner 看到的每个动作的帧为首帧、末帧、至多 4 帧“视角变化最大”者，外加逐帧输入与状态日志。这是廉价的镜头切换/关键帧检测用于 LLM 上下文压缩，可直接迁移到视频 agent 的观测摘要管线。

**（3）Baseline agent 三件套。** Planner 为 GPT-6.1 Sol 或 Gemini 4 Argon（API 调用、无微调、**无音频**），思考期间游戏冻结。每步输入：当前视图、上一动作及其预期与实际结局、该动作的帧与日志、本循环近期动作及 planner 自评、上一计划；决策前可请求任意历史帧。输出：动作成败判断、计划保持/修订（目标-步骤列表）、当前视图描述、下一条第一人称动作指令。planner 被刻意**不告知**三件事：阅读/对话能获得信息、循环时长、循环总数——即不告诉它世界的基本元结构，只给总体目标（探索、学习世界、保命）。描述与动作一律以外观点名事物，游戏名只用于行星、工具与屏上文字；唯有 KB 记录内在学到名字后改用真名。

**（4）混合动作接口。** 需边看边做的动作（走向某物、飞行、降落）交学习控制器；精确/离散输入（屏显按钮、对话选项、短精确转向）由 planner 逐帧自写手柄输入，至多 170 帧（约 9.5 s），期间看不到中间视图。控制器实际承载率：GPT-6.1 Sol 带 KB 501/2509（20%）、不带 KB 760/3347（23%）、Gemini 4 Argon 仅 27/930（3%，loops 1–7）——前沿规划器大多绕开控制器自己写输入，是意图-执行缺口的直接量化证据。

**（5）实体中心知识库。** 每条记录 = 实体、类型、属性-值对、支撑帧区间（如 loop 2, frames 300–340）、习得方式短注；程序自动补写 loop/动作号与首帧天体及 xyz。**append-only**：同一事实再次见到按同实体新增记录、证据累积而非合并；记录矛盾时要求写 contradiction record（标 accepted/rejected/undecided + 理由，允许解释为“不同时刻皆真”）——但 GPT-6.1 Sol run 八个循环**一条也没写过**。KB 从 loop 3 的 618 条涨到 loop 8 的 1,046 条、约 40 个实体。条件设置（Table 3）：不带 KB 的 run 仍有历史帧请求与本循环动作日志，差异在实体列表/记录检索/写记录，以及是否被告知将用 Entity Knowledge QA 评估——两个因素混淆，作者在局限中明说归因不可分。

**（6）控制器：VPT 谱系的小容量视频模仿。** 5 小时人类游玩切成 8,436 个原子动作，目标级标签以外观命名、可仅从首帧理解；标注流程为人写→LLM 润色语法→人定稿；每个被测 LLM 再对全部动作重标注（先只看首帧提候选，再看参考标签与全程写终标签），各训练自己的控制器。架构：冻结 ImageNet ResNet-34 全分辨率编码，FiLM 做文本条件，每帧池化为 16 个区域 token；冻结 T5-base 编码标签与描述；6 层 transformer 在近期步与文本上注意力，输出 binned 摇杆/扳机位置、13 个按钮与 end-of-action；结束条件为结束概率连续 6 步 >0.4 或满 170 步。可训练参数仅 26.8M；每 planner 用一张 180 GB GPU 训 2 epoch（17,148 步、窗口 32、约 2 小时）。刻意不用 RL：让执行不忠实时责任清晰落在 planner 的决策上，而非被控制器学习掩盖。

## 4. 实验结果

三个条件各一 run、八循环：GPT-6.1 Sol 带/不带 KB、Gemini 4 Argon 带 KB；QA 只作用于带 KB 的两个 run。

**进度（Table 4）：**

| Run | Places@L8 | Places 八循环求和 | Rumors@L8 | Rumors 求和 |
|---|---|---|---|---|
| GPT-6.1 Sol + KB | 57 | 346 | 9 | 60 |
| GPT-6.1 Sol − KB | 47 | 272 | 6 | 37 |
| Gemini 4 Argon + KB | 30 | 172 | 1 | 6 |

**Entity Knowledge QA 关键行（Table 5，GPT-6.1 Sol run，括号内 Sol/Gemini 评委）：**

| Loop | Answered | Correct % | Grounded % | Score |
|---|---|---|---|---|
| 1 | 27 | 14.6 / 14.6 | 11.0 / 11.6 | 7.3 / 8.5 |
| 3 | 39 | 20.7 / 21.3 | 12.8 / 15.2 | 4.9 / 9.1 |
| 8 | 48 | 26.8 / 26.8 | 15.9 / 18.3 | 4.9 / 9.8 |

Gemini 4 Argon run：正确率 0.6%（L1）→ 7.9–8.5%（L8，两评委），但 Sol 评委下综合分自 loop 5 起为负（−1.2 / −1.8 / −3.0 / −0.6）——答对但无法自证的答案超过了能自证的。

**核心发现是三视图发散，四条证据链：**
1. **发现早停 vs 探索/记忆续涨**：GPT-6.1 Sol run 的 rumor 揭示在 loop 3 封顶于 9 条、此后为零；同期 places 从 44 涨到 57、KB 从 618 涨到 1,046 条。位置探索与记忆堆积在知识发现停止后仍持续增长。
2. **正确率涨、grounding 滞后**：正确答案占全部题目从 14.6% 升至 26.8%；答了的大多对（loop 8：48 答中 44 对，≈92%），但 loop 8 的 44 个正确答案仅 26–30 个（59–68%，取决于评委）被自身证据支撑。综合分在 Sol 评委下从 loop 1 的 7.3 **降到** loop 8 的 4.9（全程峰值即首循环；Gemini 评委下 8.5→9.8）——正确率的增益被 grounding 缺口吞掉。
3. **引用来源前倾**：loop 8 的 44 个正确答案中 34 个引用 loops 1–3 的证据、21 个只引 loop 1；loop 4 起的新增正确答案 21 个中 **12 个只引更早循环**——后期“知识增长”过半来自旧证据的重新组织与检索，而非当循环新观察。作者提醒：引用只表明证据在哪，不表明首次习得时间。
4. **评委分歧集中于 grounding**：总一致率 GPT run 97.5%（κ=0.93）、Gemini run 97.6%（κ=0.80），正确性上 κ=0.97/0.99 几乎不分歧；但 grounding 上 Gemini run 仅 61.8%、κ=0.29（76 个答案），GPT run 92.4%、κ=0.83（275 个答案）；Sol 评委始终更严。高一致部分来自多数题未答。

按知识类型（loop 8，Sol 评委）：spatial 4/4 grounded、identity 10/14、appearance 3/5、function 4/7、causal 3/5、narrative 仅 2/6、temporal 0/3；**procedural 10 题 0 正确**（所有 run）——而 procedural（如“借水母过电层”）恰是门控进度的知识，与 rumor 早停互为印证。

## 5. 消融要点

论文无形式化消融，可用对照切片及口径如下：

- **KB 有/无（混淆 QA 评估告知）**：places 57 vs 47、求和 346 vs 272、rumors 9 vs 6、求和 60 vs 37。方向上 KB+评估告知有利，但两因素未分离，作者自认不可归因于 KB 单独作用。
- **planner 家族**：Gemini 4 Argon 带 KB 几乎不推进（1 rumor、30 places、QA 正确率峰值约 10%），其控制器使用率仅 3%——以自写输入为主的策略在 3D 连续控制中代价高；但单 run 无法区分能力差距与动作接口适配差距。
- **评委家族**：grounding κ 从 0.83（275 题）掉到 0.29（76 题），且分歧原因被作者定位：运动中采证的**首帧位置校验**失败、单条证据失败时的处置不同、仅一位评委会对长引用区间追加请求帧。对一切用 LLM 评委做视频/具身判定的管线，这是必须报告的噪声底。
- **引用来源分解**：12/21 的后期新增正确只引旧证据，说明 loop 3 后 KB 的增长（618→1,046）主要是对既有证据的复述性堆积，而非新知。
- **知识类型分解**：题量不均衡（narrative+identity 占 77/164，temporal 6、procedural 10）、单 run 计数小、标签无第二标注人，作者明示只能当观察不当效应。
- **已声明的测量局限**：每条件单 run；rumor 停滞原因（规划/控制/时间预算）未分离；评委未与人比对、无实体外观参考信息（帧里看得到实体但没点名会导致误判不 grounded）、位置校验只在首帧；grounded ≠ 因果（答案未必因该证据而产生）；两个 planner 可能在预训练中见过 Outer Wilds，grounding 校验削弱但不消除污染；二元计分会把“真但欠具体”的答案判错。

## 6. 贡献与启示

**测量学贡献**：（i）把“改进”拆成同 run 三视图并强制证据对齐，答对不能自证即倒扣，使预训练污染与瞎猜在分数上显形；（ii）进度用发现曲线下面积，回避最优参考策略与显式奖励的缺失；（iii）以循环数为主成本、规划期不计游戏时间，成本核算干净。这套口径对任何跨回合自我改进系统通用。

**实证启示**：记忆堆积与发现脱钩（618→1,046 条记录、0 新 rumor）；正确率的增长大半来自旧证据的重新可用；执行通道（控制器仅承载 20%/3% 的动作）可能是进度的真实瓶颈，且与知识失败纠缠；procedural 知识全军覆没直接封死了知识门控路线的进度。

**与音视频技术的上下游关联**（本文属具身 agent 基准，但证据层完全是音视频工程问题）：
- **上游（采集/编码/摘要）**：帧+手柄输入+位姿遥测按 0.056 s 步长同步、可冻结恢复的多流录制，是可复用的具身数据采集范式；“视角变化最大处的 ≤4 帧”关键帧抽取是面向 LLM 上下文预算的廉价视频摘要；控制器本身是 VPT 谱系的视频模仿学习（冻结 ResNet-34 + FiLM + T5-base，26.8M 可训练参数、5 小时/8,436 动作即训完），其被 planner 大比例绕开的事实说明“小控制器+大模型规划”的分工在 3D 连续控制里尚未闭合，这对游戏 agent 与视频-动作学习都是负结果信号。
- **下游（视频理解与评估）**：Entity Knowledge QA 实质是**自我录制视频上的带时序定位的归因式 QA**——引用需同时通过帧存在性、天体一致性、30 单位几何校验，再由 LLM 评委做视频蕴含判定，可视为 NExT-GQA 式 video grounding 的具身硬版本（源视频是 agent 自己的第一人称录像，且几何校验提供了帧级 grounding 之外的第三重验证）；双家族评委+逐项 κ 报告的协议，直接对接 LLM-as-judge 自偏好问题，可搬进视频评估器的评测；“评委可主动请求更多帧”是主动证据检索的雏形。
- **模态空白**：planner 与控制器均不接收音频，证言通道被降维为屏上文字的读取问题；对话音频、环境声是彻底未用的信号——音视频联合的具身 agent 在此基准上有明确的改进空间，也意味着当前“证言”证据的采集难度被人为抬高。

## 7. 与其他论文的联系

- **2611.23219（Do LLM Agents Still Need to Be Told How to Self-Improve?）**：AstronautBench 刻意不告知 planner “阅读/对话给信息”“循环时长”“循环数”，正是不告知自改进方法的测量端对应物。该文研究仅给原语、资源与目标时智能体能否自主构建自改进算法；AstronautBench 则为这类系统提供“改进是否落地为证据支撑的知识”的验收协议，二者构成方法-评测的互补。
- **2611.23068（The Resolution Hypothesis）**：该文论证智能体进化的瓶颈在噪声评估无法可靠识别改进。AstronautBench 恰是“识别改进”的仪器，其全部发现都是分辨率问题的具身实例：单看正确率高估改进、单看 rumor 低估、grounding 评委 κ 低至 0.29——评估噪声直接决定“有无改进”的结论方向（Sol 评委下综合分八循环净下降）。
- **2611.14326（FGSE：证伪门控的自我进化）**：FGSE 把经验教训作为可证伪假设、经三类探针验证后才写入记忆。AstronautBench 的 baseline 是 append-only KB、contradiction record 机制全程零触发、后期新增正确答案过半只引旧证据——正是“未经证伪 gating 的记忆堆积”的病灶样本；FGSE 式写入前验证是直接对症的机制候选，而本基准的 grounding 校验可充当其外部检验门。
- **2611.26806（MedicalRSI）/ 2611.23890（EVA-RSI）**：两者均为递归自我改进框架（医学域的 Solver/Improver 模型-框架协同进化；视频评估器的多智能体递归改进+纳什议价）。AstronautBench 与它们构成“系统 vs 测量”的互补：RSI 系统声称的跨回合增益可用三视图检验是否为证据支撑的真增益；反向地，EVA-RSI 改进评估器的思路正对应本文暴露的 grounding 判定分歧（κ=0.29）与评委恒严/恒宽的偏置问题。
- **2611.14949（RSI-PDEbench）**：同为 RSI 基准但域相反——PDE 求解有可验证通过率与调用成本作硬指标，AstronautBench 无显式奖励、进度被知识门控且依赖不完美控制。两者一起界定了 RSI 评估谱系的两端：符号可验证 vs 具身稀疏隐式，后者必须靠多视图+归因校验补足单一成功信号缺失的问题。
