## 1. 背景与动机

医疗 LLM 智能体（在 EHR 系统上经 FHIR 请求或 SQL 查询完成检索、记录、下单等动作）部署后大多冻结，跨患者复现同类错误。现有自我改进沿两条路线：权重级（在自身尝试结果上训练底层 LLM，如 STaR、multi-turn RL）与上下文级（更新支撑临床工作流的技能/工具/记忆等 medical harness，如 GRASP、Evo-MedAgent）。两条路线的共同缺陷是改进策略本身固定——它从不学习“哪些改动真正有效”，从而封顶智能体上限。论文的量化动机：MedAgentBench 上，9B 智能体配前沿模型 GPT-6.1-Sol 写的 harness 解 51.6% 任务，而配在智能体自身结果上训练过的 9B 改进器写的 harness 解 61.2%——“学会改进”本身有独立增益，由此导向递归自我改进（RSI：同时改进智能体与其改进策略）。

医学场景落地 RSI 有两个具体障碍。其一，临床工作流几乎没有参考 harness，各医院流程与系统细节不同，改进策略只能从尝试结果反推动作是否有效。其二，改进目标非平稳：论文用镁补充任务举例——初期错误是未做 24 小时时间窗过滤，“把时间过滤写成显式步骤”的技能此时有效；一旦学会过滤，错误迁移到剂量选择，同一改动失效。改进器必须持续跟踪一个正在变化的 Solver。核心问题：医疗智能体如何从自身结果持续改进其改进策略。

预备实验（MedAgentBench 训练任务、Qwen3.5-9B、每任务 8 次尝试）给出四个支撑设计的事实：(1) 仅 RL 训练时，首轮 42% 训练任务 8 次全失败（无梯度信号），末轮仍 19%；引入“从失败写的 harness”后任意轮至多 19%、末轮 3%——harness 把不可学任务转为可学任务。(2) 在此前失败任务上裸跑，仅 RL 模型重复同一错误 68%，RL+失败 harness 训练者为 42%——失败经验进入了权重。(3) 前 5 轮 29% 的自写 harness 劣于无 harness（末 5 轮降至 16%）——harness 是否有效只能事后判定，必须有结果反馈的奖励。(4) 每轮 harness 相对裸 Solver 的增益从首轮 8 点升至末轮 16 点——模型越强 harness 价值越大，首轮后冻结的 harness 逐渐失效。结论：模型与 harness 必须每轮共同演化。

## 2. 方法总览

形式化：任务 x 带患者上下文；临床工作流 τ 把共享相同步骤、仅患者记录不同的任务分组。智能体是模型 π_θ 经医疗 harness H 行动，动作接口与执行循环固定，演化的只有技能/工具/记忆；H0 为不含任何工作流技能的初始 harness。评分器（智能体不可见参考答案）给出结果 r∈{0,1} 与过程分 μ = r + (1−r)·c/2（c 为通过检查项比例），性能 J(θ,H)=E[r(ξ)]。RSI 被定义为 (θ_{t+1}, H_{t+1}, ψ_{t+1}) = U_{ψ_t}(θ_t, H_t, ψ_t, D_t)；固定 ψ 即退化为普通自我改进——现有两类方法均属此退化形式。

MedicalRSI 的机制核心是一个模型经两套提示模板扮演双角色：Improver I_θ(H|P_τ) 从工作流证据写 harness，Solver S_θ(ξ|x,H) 按 harness 执行。由于 ψ_t = θ_t（改进策略的参数就是智能体自身权重），对智能体的任何权重更新同时更新改进策略——这是满足 RSI 定义的充要构造。每轮流程（Algorithm 1；共 10 轮，每轮抽 13/26 个训练工作流、每工作流 20 任务）：① Solver 以温度 0 用 H0 试全部任务，同时产生奖励基线与工作流证据 P_τ（至多 5 条覆盖不同错误类型的失败 + 至多 2 条成功对照，含指令上下文、轨迹、结果反馈，绝不含参考答案）；② 若 memory 存有该工作流的 M_τ，先以当前 Solver 温度 0 复测，Improver 再写 G=8 个候选——一半修订 M_τ、一半从零写（两类不进同一对比组）；③ Solver 以温度 1 用每个候选重试全部任务，另加 N=2 次 H0 尝试；④ harness 以反事实增益 R(H) 计酬，Solver 尝试以 r 计酬，组相对优势合成单一损失 L(θ)=½[L_clip(D_imp)+L_clip(D_sol)]，每轮仅 2 步 AdamW；⑤ memory 仅当新候选在温度 1 与 0 两次测评中增益高出存量 ≥δ=0.03 才替换。RL 前先做 SFT 暖启动。测试时权重冻结：有存量技能直接用；新工作流先用 H0 试一批任务，Improver 以 3 个最相似训练工作流（任务文本 TF-IDF 余弦）的存量技能为参考写 K=16 个候选，按候选均值报告。训练用 LoRA（rank 64/α 128），采样开销大而更新极轻（每任务每轮约 1+G+N 次回放外加 memory 复测、每轮 2 个优化步），是典型的 rollout 瓶颈型 RL。

## 3. 关键设计

**失败接地的工作流证据。** P_τ 取自最新尝试，失败样本按错误类型覆盖挑选（非法动作、被拒订单等各取其一），成功样本作对照；每条还标注结束方式（应答或达轮次上限）。证据不暴露参考答案、正确流程与评分检查项——奖励信号完全来自结果反馈，这是无参考 harness 前提下方法成立的根基。

**反事实增益奖励。** 每轮温度 0 的 H0 尝试作逐任务基线，候选 harness 的奖励为其带来的提升：R(H) = 先按 case type 内平均、再对 case type 等权平均的 [u(ξ_H)−u(ξ_H0)] − λ(H)，其中 u = (r+μ)/2（失败尝试至多 0.25，部分进度计分）。case type 由评分器标注（如“任务是否需要下单”），等权处理抵消多数类主导——需下单的少数患者与不需下单的多数患者对奖励影响相同，是临床公平性的工程化表达。λ 为长度惩罚 min{0.1, 5×10⁻⁴·max(0, n−1500)}（工具 SQL 超 2000 字符部分不计入 n）；无法解析的候选直接 −0.5 且不执行；有效评分任务数 <15（MedAgentGym 为 10）的候选无奖励。该奖励“修好失败计正、弄坏成功计负”，只依赖评分器反馈——这是方法能跨医院流程、跨数据库迁移的原因。

**双角色联合优化。** 组构造：Improver 的组为同一提示写出的候选（修订组与从零组分离），优势=奖励减组均值（不除标准差）；Solver 的组为同一任务上 G 次 harness 尝试加 N 次 H0 尝试（memory 使 harness 尝试为 G+1 时随机抽 G 保持组大小一致）。损失为两角色 GRPO clip 损失等权平均，逐角色按 token 平均（长 harness 与短动作等权），非对称裁剪 ε_low/ε_high = 0.2/0.28（DAPO 风格）。关键机制：某任务在 H0 下从未解出、但某候选解出时，Solver 组内出现 r 差异从而产生梯度——这正是“失败经 harness 转为学习信号”的实现路径。每轮保留 N 次 H0 尝试是为维持裸 Solver 能力（新工作流首遍必须用 H0）。

**SFT 暖启动。** 用 GPT-6.1-Sol 从 Base Agent 失败写的候选做监督数据：保留比 Base 多解 ≥2 任务且距最佳 ≤3 者（每工作流至多 12；无达标者保留“不劣于 Base”的至多 4 条），LoRA 训 3 epoch（lr 1e-4，cosine）。效果：RL 前两轮不可解析率 11%→2%、超长率约一半→13%；从空 adapter 直接 RL 十轮后总体低 15.6 点。暖启动提供格式与写法先验，主增益仍来自 RL。

**harness 组件与 memory。** 技能为三段式自然语言流程（When to use / Steps / Pitfalls，Pitfalls 直接取自证据中的错误）；工具为带文档的 SQL 视图集合（Solver 只见名称/列/文档，环境在查询前建视图）；memory 每工作流存最优技能或工具，替换需双温度确认且增益超 δ=0.03——保守门控在 Improver 不稳定阶段防止性能回退（呼应前 5 轮 29% 有害 harness 的现实）。写入具体患者 ID 的技能被丢弃，防过拟合到个体。

**测试期自适应。** 新工作流从首批 H0 失败写 16 候选（温度 0.7、top-p 0.8），报告均值即“随机部署一个候选”的期望结果，无需评分器；改从训练任务失败写 harness，各方法总体变化 ≤1.2 点；去掉测试期结果反馈，MedicalRSI 仅损 0.6 点（其余用反馈的方法损 1.6–10.0，Reflexion 损 10.0）——训练过的 Improver 已能仅凭轨迹定位错误。

## 4. 实验结果

设置：主基准 MedAgentBench（FHIR 环境，每轮一个动作 GET/POST/FINISH，至多 8 轮），32 个工作流（v1 的 10 + v2 的 10 + 12 个新类型），26 训练 / 6 留出为 OOD，每工作流 20 训练 + 10 测试任务，共 520 训练 / 320 测试（60 为 OOD）。第二基准 MedAgentGym 的 EHR-SeqSQL 子集（MIMIC-III 只读 SQLite，时间固定 2105-12-31），按“掩码值后的 gold SQL 结构”重切分为工作流（未见工作流与训练工作流查询模式 token Jaccard 相似度 <0.8），同样 26/6 划分。评测遵循 Harness-R1 协议：写 harness 的方法先让 Solver 裸测试任务，改进器从尝试+结果反馈（无参考答案）写 16 个技能，取均值；训练方法在 10 轮后测试。

## 6. 贡献与启示

**方法学。** ψ=θ 的同一化是 RSI 的最简可行实现：把“学会改进”折叠进标准策略训练，无需第二模型或显式元学习架构；反事实增益奖励（以无 harness 行为为基线、case type 等权、只吃结果反馈）是“无参考标准领域”的通用配方——凡有可验证结果的闭环均可套用。

**实证。** 超加性协同（10.1+7.4 < 23.6）证明权重与上下文是互补通道，且上下文资产随模型进步贬值、须与训练共调度重写——这对所有维护 prompt/技能库的工程团队是直接警示。错误随学习在类型间迁移（时间窗→剂量）说明一次性错误分析不构成稳定改进策略。

**工程。** 采样瓶颈格局（每任务每轮约 11 次回放、每轮 2 个优化步）意味着扩展瓶颈在 rollout 吞吐而非优化器；memory 的 δ 门控加双温度确认是廉价的回退保护；harness 文本反而降低输入 token（轨迹缩短）——上下文工程的净成本取决于是否减少交互轮次，本工作给出正例（每解任务 token 约为纯 RL 一半）。

**局限（依文本）。** 训练期奖励仍依赖评分器与逐任务 H0 基线（回放开销）；早期 29% 有害 harness 仅靠门控而非统计保证兜底；OOD 绝对分 66.1 仍有空间；每工作流仅 20 训练任务，评测口径为 16 候选均值（期望值而非最优）。

**音视频上下游映射。** “工作流=共享步骤、变化内容”的抽象直接对应 AV 流水线中重复性的 QC、字幕-审核-发布、高光抽取等流程；harness 的技能/工具/记忆分别映射为检索窗口规格、决策阈值、工具调用序列的自然语言/SQL 表述——论文中“24 小时检验时间窗过滤错误”与媒体时间范围查询错误同构。上游：多轮 GRPO/DAPO 基础设施与 VLM 底座可原样复用；下游：视频评估器与长视频理解智能体可移植“双角色共享权重 + 反事实增益奖励”的训练侧机制，替代当前固定或未训练的改进器；在多轮检索主导 token 预算的长视频智能体场景，“harness 缩短轨迹从而降低输入 token”的发现具有直接成本意义。

## 7. 与其他论文的联系

- **SkillDuet（arxiv:2611.12109）**：最近亲——以响应反馈协同演化 LLM 参数与外部技能库，实现技能级 RSI。差异在 MedicalRSI 用单一共享权重的双角色模型（而非独立的技能库演化机制）、以对 H0 的反事实增益为奖励并做 case type 等权、memory 带 δ 门控。两者在“模型+技能联合演化优于任一单通道”上跨域互证（临床 EHR 对一般响应反馈）。
- **EVA-RSI（arxiv:2611.23890）**：同一 RSI 范式在视频域的实例——用代理考试与纳什议价递归改进视频评估器的时序/运动质量判断。分工互补：EVA-RSI 做 AV 生成侧的评估者改进，MedicalRSI 提供训练侧机制（权重共享 Improver + 免参考奖励）；“用反事实增益训练视频评估器的改进器”是二者结合的直接外推，也是本工作对音视频技术最具操作性的迁移方向。
- **TRUST（arxiv:2611.10787）**：用在线多重假设检验控制 RSI 智能体的错误进化率并给统计保证。正对本工作的开放缺口：前 5 轮 29% 有害 harness、门控仅为启发式 δ 边际；TRUST 式保证可加固临床部署及任何“坏 harness 静默污染输出”的 AV QC 闭环。
- **LongCapHarness（arxiv:2611.10463）**：能力引导的自动 harness 挂接长上下文推理，免数据合成与后训练、成本低于基线 50%。与 MedicalRSI 同持“harness 经济学”（本工作量化为每解任务 20.8k 对 40.4k token）；LongCapHarness 处于“未训练 Improver”一端，而 MedicalRSI 证明该端被训练过的 Improver 大幅支配（51.6 对 85.1）；其长上下文场景即长视频理解设定。
- **WeightLoop（arxiv:2611.07319）**：以有界参数编辑程序加实验反馈持续改写已部署权重、免重训练——权重级通道的替代实现；其实验反馈闭环与本工作的反事实增益奖励同构，可补足 MedicalRSI 测试期目前仅 harness 自适应、权重冻结的限制。
- 同期 RSI 扩散：InfraRSI（训练基础设施，五阶段验证工作流，呼应本工作的门控式 memory 更新）、RSI-PDEbench（PDE 求解，通过率升且调用成本降，与本工作“每解任务成本减半”一致）、TrainExplorer（自主后训练的规划-执行解耦）——共同表明 RSI 机制正在按栈的层级（基础设施/训练/评估/领域智能体）分化出专门实现，MedicalRSI 是领域智能体层在临床工作流上的代表。
