## 1. 背景与动机

机器人操作当前存在三条主线。端到端路线中，VLA 模型在大规模机器人数据与预训练视觉语言骨干上构建观测—指令到动作的映射，动作头多采用扩散或流匹配生成器；WAM 路线则利用视频生成先验，或以预测未来引导动作，或做视频—动作联合建模。二者均依赖大规模机器人训练数据，在未见环境泛化与长程操作可靠性上有明显短板。第三条 agentic 路线用 VLM 的推理规划能力分解任务、经控制接口驱动机器人，免参数更新、支持反馈驱动执行，是本文的立足点。

论文针对 agentic 框架的三个结构性痛点：(i) **记忆组织不足**——长程任务需要跨时间尺度、跨粒度地维护子目标进度与执行历史，并在尝试间、任务间保留经验；(ii) **失败归因不确定**——操作失败可能源于动作 grounding 不准、前置条件不满足或状态约束被破坏，而执行反馈只暴露可观测结果、不给根因，诊断极易滑向无依据的合理化解释；(iii) **自改进能力有限**——即便识别了错误，反思若与后续执行隔离、缺少积累/验证/精炼机制，同类失败会反复出现。

定位上，本文与 RoboDawn（VLM 直接下发控制指令、五类原子命令接口）同 setting，与 HarnessVLA（解析基元 + 冻结 VLA + 记忆引导规划）同属“harness”思路，但强调失败诊断与纠正性指导之间的显式闭环。与 SenseNova-RoboRSI 的关键区别在于：后者以重评估验证后才保留 harness 修改，本文以后续尝试的执行结果作为隐式验证信号。核心主张：**不更新模型参数，通过递归精炼文本化的执行 harness（操作知识库）实现持续性能提升**。

## 2. 方法总览

框架为 Actor/Reflector 双智能体 + 分层记忆 + 递归 harness 更新的闭环。

**Actor（冻结 πθ）**：每步依据任务指令 g、视觉观测 o(k,t)、本体感知状态 s(k,t)、当前 harness H(k) 与工作记忆 M^W(k,t) 采样动作 a(k,t)。动作接口为五类原子命令 {move, rotate, point, gripper, home}（沿用 RoboDawn 接口），分别对应末端平移、旋转、预定义姿态控制、夹爪开合与回 home 位。涉及末端运动的指令由 harness 将动作参数转换为 SE(3) 目标位姿 X̂(k,t)，再解逆运动学：q* ∈ argmin D(FK(q), X̂)，可行域为满足关节限位与碰撞约束的 Q_valid，由解得关节构型规划轨迹执行。每步动作后以反馈 f(k,t) 与更新后的观测/状态跟踪进度。完整轨迹 τ(k) = {(o, s, a, f)} 即反思证据。值得注意的是 harness 在执行侧并非纯 prompt 指导，还参与动作参数到位姿的落地转换，是执行知识而非装饰性文本。

**Reflector（冻结 Rϕ）**：每轮尝试后输入 (g, τ(k), r(k), H(k), E(k)) 产出诊断 d(k)；框架随后由 ΔG(k) = Generate(d(k), H(k), E(k)) 把诊断转为候选指导，再由 H(k+1) = Update(H(k), ΔG(k), E(k)) 融入既有操作知识。闭环为：执行 → 证据诊断 → 指导生成 → harness 精炼 → 下一次执行。

Harness 内容按五个操作类别组织（与反思分类对齐）：接触与位姿控制、运动与协调、任务协议与完成、空间 grounding、状态跟踪与恢复。这构成一个任务级、可增量修订、可跨尝试复用的文本化知识库，替代了对模型参数的更新。

## 3. 关键设计

### 3.1 分层记忆架构

按“时间尺度 × 信息粒度”正交分解为双层四模块。

**短期工作记忆**（服务 Actor 单 episode 决策）：
- *Condensed Progress Memory*：递归摘要 Mc(k,t+1) = Summarize(Mc(k,t), e(k,t))，将已完成子目标、待办操作、环境变化、执行约束压缩为紧凑表示，解决长程任务子目标进度散落于交互历史、难以维持一致任务态的问题；
- *Detailed Execution Memory*：按时间序追加 Md(k,t+1) = Md(k,t) ⊕ e(k,t)，保留观测/状态/动作/反馈的细粒度记录，支撑反馈驱动的动作调整，同时是 Reflector 失败分析的原始证据源。

**长期经验记忆**（服务 Reflector 跨 episode）：
- *Task-Specific Memory*：Es(k+1)(i) = Update(Es(k)(i), r(k), d(k), ΔG(k))，按任务身份 i 记录历史结果、诊断错误与纠正指导（同一任务身份跨不同指令共享），用于捕捉重复失败模式；
- *Cross-Task Memory*：Ex(k+1) = Generalize(Ex(k), Es(k+1)(i))，从任务特异经验抽象可迁移原理（空间 grounding、接触控制、动作协调、基于反馈的恢复），供相关新任务的反思调用。

该设计的核心权衡是：摘要表示保进度但不保细节，详细记录保细节但上下文膨胀——两模块分工使 Actor 决策与 Reflector 取证各取所需。

### 3.2 证据驱动的经验反思

针对“无约束反思产生观测不支持的归因”这一反思类方法通病，本文强制 d(k) 由具体执行证据（τ(k)、r(k)）加累积经验（E(k)）grounding，且每次反思结果强制唯一归入五类互斥操作类别：Contact & Pose Control（抓取构型、接触位置、夹爪操作、物体朝向）、Motion & Coordination（动作排序、臂协同、运动规划）、Task Protocol & Completion（任务要求、执行限制、成功条件、终止判据）、Spatial Grounding（目标识别、空间关系解释、坐标 grounding）、State Tracking & Recovery（进度跟踪、结果验证、反馈解释、失败恢复）。分类学带来三重收益：诊断结构化、与 harness 内容类别直接对齐（指导写入位置明确）、可统计失效分布以指导迭代（实验部分给出五类占比）。

### 3.3 递归 harness 自改进

ΔG(k) 的定位不是抽象教训，而是**带触发条件的操作级规则**（如“转移前抬高末端以避免低间隙碰撞”）。Update 以累积经验为上下文执行 Retain/Revise/Reuse 三类操作：保留有效指导、消解不一致、按执行证据精炼指令。验证机制是隐式的——H(k+1) 指导下一次尝试，其轨迹与结果再进入反思，指导的正确性由后续执行成功率背书，而非独立的重评估门控。相比 SenseNova-RoboRSI 的显式重评估保留策略更轻量，但存在将未验证指导写入 harness、污染后续执行的风险；论文以消融中"w/o Evidence Grounding"的掉点间接说明证据约束部分对冲了该风险。

## 4. 实验结果

**设置**：backbone 为 GPT-6 Astra（medium reasoning 为默认档），每 episode 限 45 轮交互；RoboTwin 2.0 / RoboSPA / 真实任务每任务 10 个 episode，RMBench 每任务 20 个；真实平台为 Piper 机械臂。基线覆盖 VLA、WAM、agentic 三类。

**RoboTwin 2.0 C2R**（50 任务，Clean-to-Randomized）关键行：

| 方法 | Shots | SR (%) |
|---|---|---|
| π0.5 | Full Set | 46.0 |
| LingBot-VLA | Full Set | 50.4 |
| GigaBrain-0.7（最强 VLA） | Full Set | 67.9 |
| PrismWAM*（最强 WAM） | Full Set | 75.5 |
| HarnessVLA (CC) | Full Set | 58.4 |
| RoboDawn (GPT-6 Astra) | 0 | 53.2 |
| RoboDawn (GPT-6 Astra) | 1 | 73.6 |
| **Ours (GPT-6 Astra)** | **0** | **82.4** |

同 backbone 同零样本下超 RoboDawn 29.2 pp；零演示设定下超使用完整演示集的最强 VLA（GigaBrain-0.7，+14.5 pp）与最强 WAM（PrismWAM，+6.9 pp），超 HarnessVLA 最佳变体 24.0 pp——改进归因于框架而非底层模型能力。

**RoboSPA-Spatial L5**（24 任务、五类）：平均 94.0%，超最强基线 RoboDawn（65.6%）28.4 pp，五类全部第一，CVR 从 24.0% 拉至 98.0%；L1–L5 全难度维持 94–99%，而对比方法随难度显著衰减。**RoboSPA-Long L5**（32 任务）：SR 59.5% / PS 74.9%，超 RoboDawn 18.1 / 18.5 pp；MIP 类较最强基线提升 64.0 / 64.8 pp（SR 16.0→80.0）。摘要口径的 RoboSPA 综合 76.7% 恰为空间（94.0）与长程（59.5）两子集的非加权均值。

**RMBench**（9 个记忆依赖任务）：平均 94.4%，超最强基线 MaP-WAM（83.3%）11.1 pp；5 个任务 100%，其余四个均 ≥85%。RoboDawn 在此仅 62.8%（Swap Blocks 为 0%），说明无结构化记忆的 VLM 指令控制在记忆依赖场景崩塌，直接验证分层记忆设计的必要性。

**真实世界**（3 任务）：Letter Arrangement 90.0%、Block Placement 100.0%、Block Stacking 100.0%，均值 96.7% vs π0.5 的 40.0%（+56.7 pp）。

**Backbone 与推理强度**（RoboSPA-Long 口径）：GPT-6 Astra 三档推理强度下 SR 59.5–61.1%、PS 74.9–75.5%，低→高无一致增益——backbone 能力比 reasoning effort 更关键。闭源普遍强于开源：最强开源 Qwen3.8-Max 仅 29.0% SR / 50.4% PS，Claude-Opus-5.5 为 36.4%，Gemini-4-Argon 32.7%，GLM-5.3-Flash 14.6%，DeepSeek-V4.1-Flash 12.2%。这是该范式的部署瓶颈：性能天花板系于前沿闭源 VLM。

**递归改进曲线**（round 0→4）：RoboTwin 2.0 59.2→82.4、RoboSPA-Spatial 78.2→94.0、RoboSPA-Long 43.0→59.5、RMBench 71.7→94.4；增益集中在前几轮、随后递减。round 0 即无 harness 改进的基线配置，该曲线是“增益来自 harness 精炼”的直接证据。

## 5. 消融要点

RoboSPA-Long L5 上逐组件剔除：

| 配置 | SR (%) | PS (%) |
|---|---|---|
| 完整 Embodied-Harness | 59.5 | 74.9 |
| w/o Reflector | 43.0 | 61.2 |
| w/o 短期工作记忆 | 32.1 | 49.5 |
| w/o 长期经验记忆 | 48.5 | 65.6 |
| w/o 证据 grounding | 52.3 | 67.9 |

短期工作记忆剔除跌幅最大（SR −27.4 pp），说明长程任务的执行上下文维护是第一瓶颈——再好的反思也救不回执行中丢失的进度状态。长期经验记忆次之（−11.0），Reflector 缺失 −16.5，证据 grounding 缺失 −7.2 / −7.0，即无证据约束的反思会引入不可靠指导、反而劣化 harness。反思结果分布：Contact & Pose Control 34.5% > Motion & Coordination 22.7% > Task Protocol & Completion 21.8% > State Tracking & Recovery 10.9% > Spatial Grounding 10.1%，说明改进主要作用于低层物理交互（抓取位点、接触深度、放置释放等），同时覆盖任务协议等高层要求，佐证五分类 taxonomy 的覆盖面。

## 6. 贡献与启示

**贡献**：(1) 执行/反思角色分离的双智能体免参数更新操作框架；(2) 双层四模块分层记忆（进度摘要/详细记录 × 任务特异/跨任务）；(3) 证据 grounding 反思 + 递归 harness 自改进的完整闭环；(4) 三仿真基准加真实世界的系统验证。

**工程含义**：
- 这是机器人端的 test-time scaling 实证：4 轮 harness 精炼在 RoboTwin 2.0 上买到 +23.2 pp，把同 backbone 的指令级基线（53.2%）抬过满数据训练的端到端 SOTA（75.5%）。harness 是可沉淀、可复用、可审计的任务级资产。
- 冻结 backbone 意味着模型可热替换，但 backbone 依赖极重（开闭源 SR 差距 29.0 vs 59.5），且 reasoning effort 调不动——短期内部署受限于闭源 API，长期需开源自改进能力的补齐。
- 相对端到端路线：零演示、无训练 GPU 成本；代价是每 episode 45 轮交互的推理调用开销与反思轮次累积的 token 成本，论文未给出成本核算（见第 7 节 RSI Tax 的批评视角）。
- 隐式验证（下一轮尝试结果背书）比显式重评估轻量，但任务规模增长后 Update 中的矛盾消解复杂度、harness 检索效率未被讨论；论文将跨任务/跨本体迁移与更高效的执行反思列为 future work。

**与音视频技术的上下游关联**：上游，该范式是前沿多模态 VLM 的重负载消费方——连续视觉观测流加本体感知状态的多模态融合、长上下文管理、细粒度空间 grounding 都是直接需求；对比基线中的 WAM 路线（视频生成先验引导动作、视频—动作联合建模）本身就是视频生成模型向具身下游的迁移通道，本文结果（agentic 免训练路线零样本反超满数据 WAM）为视频先验在操作控制中的实际价值提供了参照系。下游，具身智能体产生的带成败标注执行轨迹（多视角视频 + 动作序列 + 反思文本）是视频理解/生成与 VLA 训练的高价值数据源；其“证据 grounding 反思”机制——用客观执行证据约束自我诊断——对音视频领域评估器/审核器的迭代校准具有直接的方法论迁移价值。

## 7. 与其他论文的联系

- **MedicalRSI（arXiv:2611.26806）**：架构范式同构。MedicalRSI 的 Solver/Improver 双角色模型—框架协同进化与本文 Actor/Reflector 双智能体递归精炼执行 harness 是同一范式在不同模态域的实例化（医学 LLM 智能体 vs 具身操作），二者均在冻结参数前提下把改进对象放在框架层；本文的五分类互斥操作 taxonomy 为跨域的结构化诊断提供了可对齐的分类学参照。
- **BaseRSI（arXiv:2611.24578）**：路线对照。BaseRSI 将 harness 经免训练权重编辑内化进基础 VLM，本文则保持 harness 外置（文本化指导 + 分层记忆）。外置路线可审计、可回滚、backbone 可热替换；内化路线推理时零额外上下文开销。二者互补，本文递归生成的指导流理论上可作为 BaseRSi 式内化的输入语料。
- **EVA-RSI（arXiv:2611.23890）**：同为多智能体递归自改进，但改进对象是视频评估器的运动/时序质量判断而非物理执行器，与音视频方向最直接相关。其用代理考试约束评估器改进与本文用执行轨迹证据约束失败诊断，共享“以客观证据约束自我改进”的设计原则；具身操作的成败判定本质上也依赖对视频证据的质量判断，两线的融合（用 EVA-RSI 式评估器充当本文 Reflector 的前端）是自然延伸。
- **Language Models Can Rewrite Their Own Weights（arXiv:2611.21885）**：自改进谱系的两端——权重级自改写（推理驱动、无梯度）改变模型本身并可自修复损伤；本文的框架级外置精炼保持模型冻结、经验可跨 backbone 复用。两者共同界定了“不改训练梯度”这一约束下自改进的设计空间。
- **The RSI Tax（arXiv:2611.13524）**：成本批评视角。该文指出简单有界笔记基线可在精度持平下节省 65.6–71.0% 总 token。本文的 Condensed Progress Memory 本质即结构化笔记，但递归反思、harness 更新与长期记忆都会放大调用开销且论文未报告 token 成本；按 RSI Tax 口径核算 harness 精炼各轮次的边际收益是否值回成本，是复现与落地该工作前必须补齐的实验。
